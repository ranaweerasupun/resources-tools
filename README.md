# resources-tools

Companion code for articles on [Bit to Byte Academy](https://bittobyteacademy.com).

| Folder | What it is |
|---|---|
| [`edge-ai-toolkit/`](edge-ai-toolkit/) | Code and Raspberry Pi 5 benchmark results for the [Edge AI Lab Notes](https://bittobyteacademy.com/series/edge-ai-lab-notes/) series |
| [`systemd/`](systemd/) | Example services for the [systemd services on embedded Linux](https://bittobyteacademy.com/tutorials/systemd-services-on-embedded-linux/) tutorial |
